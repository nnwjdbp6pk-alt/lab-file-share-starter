# Contributing

## Branch Strategy (Recommended)
- main: stable
- dev: active development
- feature/*: feature branches
- fix/*: bugfix branches

## Commit Messages
- feat: new feature
- fix: bug fix
- docs: documentation
- chore: maintenance

## Pull Request Checklist
- [ ] Changes align with `docs/openapi.yaml`
- [ ] Changes align with `docs/db_schema_v1.sql`
- [ ] Security checks preserved (whitelist, size limits, auth)
- [ ] Added/updated docs if behavior changed
